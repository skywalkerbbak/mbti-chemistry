## ✨ 주요 특징 (Features)

- 💖 **연인 케미 vs 🤝 친구·동료 케미**: 관계 유형에 맞춘 맞춤형 분석 조언 및 테마 전환
- 📊 **16 x 16 전 조합 정밀 매트릭스**: 256개 MBTI 페어별 점수(0~100점) 및 5단계 레벨 배지
- 🌟 **3대 정밀 분석 리포트**:
  - **환상의 시너지 (Best Points)**: 둘이 함께할 때 발휘되는 강점
  - **주의할 갈등 포인트 (Caution Points)**: 성향 차이로 부딪힐 수 있는 부분
  - **특급 솔루션 처방 (Actionable Tip)**: 관계를 더 돈독하게 만드는 구체적 실천 팁
- 🔍 **퀵 케미 랭킹 프리뷰**: 내 MBTI 기준 환상의 짝꿍 TOP 3 및 주의할 궁합 TOP 3 모달 탐색
- 📸 **인스타그램 스토리 카드 이미지 저장**: `html-to-image` 기반 2배수 고해상도 PNG 카드 즉시 생성
- 🔗 **URL 딥링크 & 공유**: 브라우저 히스토리(`pushState`/`popstate`) 및 쿼리 파라미터(`?m1=...&m2=...&mode=...`) 지원

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React
- **Build Tool**: Vite 5
- **Image Generation**: html-to-image
- **Testing**: Vitest, JSDOM (44개 단위/통합 테스트 100% 통과)
- **Deployment**: GitHub Actions & GitHub Pages

